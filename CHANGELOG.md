# Changelog

All notable changes to this repository are listed here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/). The API version (`v1`) is in the base URL; this file tracks the documentation and examples.

## [1.0.0] - 2026-10-29

### Added

- OpenAPI 3.0 description of the Relay API v1, with production and sandbox servers and webhook payloads.
- Guides: authentication, shop checkout flow, sandbox (English and French), webhooks, errors, limits.
- curl walkthroughs for shop and agency keys.
- Webhook signature verifiers for Node.js, PHP and Python, tested against a shared test vector.
- Postman collection.
